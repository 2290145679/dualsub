# 🎬 双语字幕合并 (DualSub) - MoviePilot 插件

把影片**内嵌的中英字幕轨**自动合并为**上下双行双语字幕**，支持 AI 补全缺失翻译和彩色 ASS 特效字幕。

## 功能

### 字幕合并
- 🎞️ 自动识别影片内嵌字幕轨语言（中文 chi/zho、英文 eng/en）
- 🔀 同一时间点上下双行混排（英文在上 / 中文在上 可选）
- 📦 可选用 ffmpeg 把双语字幕封回 MKV（视频/音频流 copy，不重编码）
- ⏱️ 监听媒体**整理完成（入库）**事件，自动处理新入库影片
- 🛠️ 支持手动批量处理指定目录

### 彩色 ASS 字幕（v1.8+）
- 🎨 英文黄色、中文白色，带黑色描边
- 📐 字号自适应视频分辨率（1080p / 2K / 4K）
- 🔤 也可选普通 SRT 纯文本格式
- 📺 飞牛 / Emby 等媒体服务器可识别为中文轨

### AI 字幕补全（v1.6+）
- 🤖 英文字幕存在但中文缺失时，自动调用 OpenAI 兼容 API 翻译补全
- 📝 支持多语言翻译目标（简体中文 / 繁体中文 / 日语 / 韩语 / 法语 / 德语 / 西班牙语）
- 💾 翻译缓存：相同句子不重复调用 AI，带上下文保证翻译质量
- 📊 批量调用：一次请求翻译多条，自动分批
- 🔄 失败任务自动重试（可配置重试次数）
- 🔍 可在插件详情页获取可用模型列表并选择

### 媒体浏览页
- 📂 插件详情页内置交互式媒体浏览：逐级浏览媒体库目录
- 🎯 实时探测每个视频的中/英字幕轨和任务状态
- ▶️ 点「处理」处理单个视频，点「处理当前目录」批量处理
- 📋 处理历史 Tab 显示全部任务记录

## 安装

### 方式一：插件仓库
在 MoviePilot 中添加本仓库地址：

1. 进入 MoviePilot → 设置 → 插件 → 插件仓库管理
2. 添加仓库地址
3. 在插件市场找到「双语字幕合并」并安装
4. 进入插件配置页，设置「浏览根目录」为容器内媒体库路径

### 方式二：本地安装
```bash
docker cp dualsub moviepilot:/app/app/plugins/dualsub
```
重启容器或在设置里重载插件使生效。

## 依赖

- 容器内已安装 `ffmpeg` / `ffprobe`（MoviePilot 官方镜像自带）
- 无需额外 pip 依赖（纯标准库实现）

## 配置说明

| 配置项 | 说明 |
|---|---|
| 启用插件 | 总开关 |
| 入库自动执行 | 监听整理完成事件，自动处理新入库影片 |
| 发送通知 | 处理完成后发送 MoviePilot 通知 |
| 入库生效目录 | 白名单目录（每行一个），留空=全部生效 |
| 浏览根目录 | 媒体浏览页起始目录（容器内绝对路径） |
| 字幕格式 | 彩色 ASS（中英不同颜色+描边）/ 普通 SRT / 旧版 .dual.srt |
| 处理模式 | 仅生成字幕 / 仅封回 MKV / 生成字幕+封回 MKV |
| 双语顺序 | 英文在上 或 中文在上 |
| 最小文件大小(MB) | 小于此值的视频跳过，0=不限 |
| 已有双语字幕则跳过 | 已存在字幕产物时跳过 |

### AI 补全配置

| 配置项 | 说明 |
|---|---|
| AI 补全缺失字幕 | 开关 |
| AI API 地址 | OpenAI 兼容接口地址，填到 /v1 |
| AI API Key | 密钥 |
| AI 模型 | 在详情页点「获取 AI 模型列表」自动获取，或手动填写 |
| 翻译目标语言 | 简体中文 / 繁体中文 / 日语 / 韩语 / 法语 / 德语 / 西班牙语 |
| 翻译缓存 | 开启后相同句子不重复调用 AI（带上下文保证质量） |
| 失败重试次数 | 任务失败后自动重试，0=不重试，默认 2 次 |

## 输出文件

- `<影片名>.zh-CN.ass` — 彩色双语 ASS 字幕（默认，带颜色描边）
- `<影片名>.zh-CN.srt` — 纯文本双语 SRT（可选）
- `<影片名>.dual.mkv` — 封回双语字幕的 MKV（仅 mux/both 模式）
- `<影片名>.bak` — 原视频备份（仅覆盖+备份模式）

## 工作原理

1. 监听 MoviePilot 的 `TransferComplete`（入库）事件，或手动触发
2. 用 `ffprobe` 探测视频内嵌字幕轨
3. 用 `ffmpeg` 分别提取中/英字幕轨为 SRT
4. 按时间轴重叠配对，合并为上下双行双语字幕
5. 若开启 AI 补全：找到英文有但中文缺失的时间段，调用 AI 翻译补全（带上下文、缓存）
6. 生成 `.zh-CN.ass`（彩色样式）或 `.zh-CN.srt`（纯文本）
7. （可选）用 ffmpeg 把字幕封回 MKV

## 常见问题

**Q: 为什么入库后没有自动处理？**
- 检查「入库自动执行」是否开启
- 确认影片含英文字幕轨（若只有中文无英文也会跳过，除非开启了 AI 补全）
- 查看插件详情页的任务状态

**Q: 字幕太小/太大？**
- ASS 格式会自动根据视频分辨率调整字号
- 如需手动调整，可改用 SRT 格式（由播放器控制字号）

**Q: AI 补全翻译质量不好？**
- 尝试更换更大的模型（如 gpt-4o 而非 gpt-4o-mini）
- 翻译缓存带上下文，已尽量保证质量
- 可关闭缓存强制每次重新翻译

**Q: 飞牛识别不了字幕？**
- 确认字幕格式选的是「彩色 ASS」或「普通 SRT」
- 文件名 `视频名.zh-CN.ass` 中的 `.zh-CN` 是飞牛识别语言的关键

**Q: 路径填了但扫描不到文件？**
- 确认填的是**容器内**路径，不是宿主机路径
- 确认路径已挂载到 MoviePilot 容器
