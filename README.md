# 🎬 SubGenerator 字幕生成 (MoviePilot 插件)

[![MoviePilot Version](https://img.shields.io/badge/MoviePilot-v2-blue.svg)](https://github.com/jxxghp/MoviePilot)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Version](https://img.shields.io/badge/Version-2.0.0-orange.svg)]()

全自动为 MoviePilot 入库影片合成**高清双语字幕**（外挂彩色 ASS、标准 SRT 或直接封回 MKV）。支持外挂与内嵌字幕智能嗅探对齐、主流大模型（DeepSeek / OpenAI / Gemini / Ollama 等）缺失翻译补全、可视化彩色排版与媒体库一键批量处理。

---

## 🌟 核心特性

- 🔍 **智能字幕嗅探**：
  - 自动识别影片**同名外挂字幕**与**内封字幕轨**（支持 MKV/MP4 内嵌多音轨）。
  - 智能打分优选：优先对白轨，自动过滤 SDH/CC 听障特效音轨，优先简体中文。
  - 支持**单轨混合双语**自动拆分排版。
- 🤖 **大模型缺失翻译补全**：
  - 仅在片源缺少某一侧语言（如仅有纯英文字幕、或纯日文片源）时**精准触发**，避免无谓消耗 Token。
  - 若片源已自带完整中英双轨，**毫秒级本地对齐合并，零 Token 消耗**。
  - 影视级专用 Prompt，支持批量并发与本地 SQLite 缓存，支持配置测试连通性与模型列表拉取。
- 🎨 **视觉级彩色排版与色盘**：
  - 支持 **7 种预设高对比色盘**（经典纯白、电影暖黄、暖金琥珀、科技荧光青、柔和护眼绿、浅天蓝、暖粉珊瑚）一键点选。
  - 保留**自由输入色号**（支持标准网页色 `#FFFFFF` 与专业 ASS 色码 `&H00FFFFFF`，底层自动纠偏 BGR 通道）。
  - 字号与边距根据视频分辨率（1080p / 2K / 4K）**等比自适应**，兼顾手机、平板与客厅电视大屏。
- ⏱️ **毫秒级时间轴对齐与微调**：
  - 采用二部图区间重叠聚类算法，智能对齐 1-to-1、1-to-N 与多句聚合，彻底避免字幕闪烁或抢跑。
  - 支持全局时间轴微调（正数延后，负数提前）。
- 📦 **灵活的输出模式**：
  - 仅生成外挂字幕（默认 `.zh-en.ass` / 可选 `.zh-en.srt`）。
  - 封回 MKV 成为全新内置字幕轨（基于 ffmpeg stream copy，无需转码，秒级完成）。
  - 或两者同时执行。
- 📊 **透明通知与任务管理**：
  - Telegram / 系统通知推送详细明细（影片名称、字幕来源、AI 调用状态、总句数与双语配对数、生成路径）。
  - 媒体库卡片式浏览与一键批量处理，带处理进度与任务日志详情。

## 🚀 安装指南

### 方法一：通过 MoviePilot 插件市场添加（推荐）

1. 打开 MoviePilot Web 管理后台。
2. 前往 **设置** → **实验室** → **插件仓库**。
3. 在仓库列表中添加本仓库地址：
   ```text
   https://github.com/2290145679/dualsub
   ```
4. 点击保存后，进入 **插件市场**，搜索并找到 **「字幕生成」**（或 **SubGenerator**）。
5. 点击 **安装** 即可完成部署！

## ⚙️ 核心配置说明

| 配置项 | 推荐设置 | 说明 |
| :--- | :--- | :--- |
| **启用插件** | 开启 | 插件主开关 |
| **入库自动执行** | 开启 | 监听 MoviePilot 入库整理完成事件，全自动为新影片生成双语字幕 |
| **发送通知** | 开启 | 处理完成后推送包含 AI 状态、字幕源和对齐统计的明细通知 |
| **生成格式** | 彩色 ASS (推荐) | 渲染支持独立字体与配色的高清 ASS 字幕；亦可选标准 SRT |
| **中文字幕色盘** | ⚪ 经典纯白 | 下拉即可快捷点选常用色，选“自定义”可在右侧输入任意 HEX/ASS 色号 |
| **外文字幕色盘** | 🟡 经典暖黄 | 下拉即可快捷点选常用色，选“自定义”可在右侧输入任意 HEX/ASS 色号 |
| **双语排版顺序** | 中文在上 / 英文在下 | 视个人观影习惯调整上下位置 |
| **AI 翻译补全** | 按需开启 | 当片源缺失中文/外文时自动调用 AI；若片源自带中英轨则自动跳过不耗费额度 |
| **AI API 接口** | 用户自填 | 支持 OpenAI 兼容接口，如 `https://api.deepseek.com/v1` |

> 🔒 **隐私与安全承诺**：
> 1. 本插件为**纯本地执行**，核心算法全部基于 Python 标准库与容器自带 ffmpeg。
> 2. 您的 API Key、NAS 地址与个人配置均**仅保存在您本地的 MoviePilot 数据库中**，绝不上报或传输到任何外部第三方服务器。
