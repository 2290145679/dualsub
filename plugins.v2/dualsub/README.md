# 字幕生成 (SubGenerator) - MoviePilot 双语字幕插件

全自动为 MoviePilot 入库影片合成高清双语字幕，支持外挂与内嵌单语字幕嗅探、大模型 AI 缺失翻译补全、彩色 ASS 独立样式排版、可选封回 MKV 与媒体库可视化看板。

## 🌟 核心价值与特性

1. **全自动闭环**：
   - 监听 MoviePilot `TransferComplete` 整理入库事件，影片转移完成后自动运行，无需任何人工干预。
2. **多源字幕智能嗅探**：
   - 同时支持视频同目录下的外挂单语字幕（`.srt` / `.ass` / `.vtt`）与视频文件内部封装的内嵌字幕轨。
3. **AI 缺失翻译补全**：
   - 彻底解决“只有纯英/纯中/纯日字幕”的痛点。当片源缺少对应语言时，自动通过 OpenAI 兼容接口（推荐 DeepSeek）批量并发翻译补齐。
   - 具备上下文感知（Context-Aware）与本地哈希缓存，大幅减少 Token 消耗。
4. **安全无损与丰富交付**：
   - 默认模式为**外挂字幕**（生成 `.zh-cn&en.default.ass`），符合 Emby / Plex / Jellyfin 命名标准，原视频 100% 保持原样零修改。
   - 可选 **MKV 无损封回** 模式：使用 ffmpeg 流复制（`-c:v copy -c:a copy -c:s ass`），秒级完成混流，原画质与音轨零损失。
5. **彩色 ASS 高颜值排版**：
   - 中英文独立字体、独立配色（如中文纯白、外文奈飞金黄）、黑色清晰描边与阴影，自动根据视频分辨率（1080p / 4K）等比缩放字号与底部边距。
6. **可视化媒体库看板**：
   - 插件内置媒体库树形浏览器，实时显示各视频的字幕状态（`[双语已生成]` / `[中英内嵌就绪]` / `[纯英(可AI补译)]` / `[无字幕轨]`）。
   - 支持一键手动单片生成、重新生成与当前目录批量处理。

## ⚙️ 配置说明

- **启用插件**：总开关。
- **入库自动执行**：开启后，自动监听入库事件并触发生成。
- **交付模式**：
  - `仅生成外挂字幕`（推荐）
  - `仅封回 MKV`
  - `生成外挂 + 封回 MKV`
- **字幕排版顺序**：支持 `中文在上 / 外文在下` 或 `外文在上 / 中文在下`。
- **AI 配置**：
  - `AI 接口地址`：如 `https://api.deepseek.com/v1`
  - `API Key`：输入大模型密钥
  - `获取模型` 与 `测试连接`：一键拉取模型列表并测试连通性。
- **媒体库浏览根目录**：容器内挂载路径，如 `/vol2/1000`。
